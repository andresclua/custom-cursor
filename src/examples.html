Examples

Eight small recipes.

Every stage is live: the cursor you are moving is the one in the code.

00

Setup

The wrapper holds children with data-lerp. This page's cursor is exactly this setup: an instant dot and a lagging ring.

Move the pointer: dot = lerp 1, ring = lerp 0.18.

<div class="c--cursor-a">
  <span class="c--cursor-a__artwork" data-lerp="0.18"></span>
  <span class="c--cursor-a__item" data-lerp="1"></span>
</div>

new CustomCursor({ element: '.c--cursor-a', hideTrueCursor: true });
01

Basic focus

Links and buttons grow the ring by default. No config needed.

A link
new CustomCursor({
  element: '.c--cursor-a',
  focusElements: ['a', 'button'], // default
});
02

Custom focus class

Give a group of elements its own class and the cursor can look completely different over them.

Grow
Grow
focusElements: [
  { elements: '.js--grow', focusClass: 'c--cursor-a--third' },
]
03

Focus with callbacks

mouseenter and mouseleave receive the cursor and the hovered element: write text, animate, anything.

One
Two
{
  elements: '.js--text',
  focusClass: 'c--cursor-a--fourth',
  mouseenter(cursorEl, el) {
    cursorEl.querySelector('.c--cursor-a__artwork').textContent = el.dataset.cursorText;
  },
  mouseleave(cursorEl) {
    cursorEl.querySelector('.c--cursor-a__artwork').textContent = '';
  },
}
04

Disable / enable

Hide the cursor on demand, for instance over an embedded player.

cursor.disable();
cursor.enable();
05

Update options

Change options without destroying the instance. Focus elements are re-bound.

Hover me after choosing
cursor.update({ focusClass: 'c--cursor-a--third' });
06

Generic focus elements

Any selector, NodeList or element works, not only links.

Card
Tag
focusElements: ['a', 'button', '.js--generic']
07

Dynamic content

After injecting DOM (AJAX, load more), call update({}) so selectors are re-evaluated.

grid.appendChild(card);
cursor.update({}); // new nodes are picked up
