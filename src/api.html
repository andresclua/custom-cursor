API

Everything the cursor can do.

The cursor on this page is a live instance. Every control below changes it right now.

Install

npm install @andresclua/custom-cursor

Quick start

Children with data-lerp are auto-discovered. 1 is instant; lower values lag more.

<div class="c--cursor-a">
  <span class="c--cursor-a__item" data-lerp="1"></span>
  <span class="c--cursor-a__artwork" data-lerp="0.15"></span>
</div>

import CustomCursor from '@andresclua/custom-cursor';

new CustomCursor({
  element: '.c--cursor-a',
  hideTrueCursor: true,
  focusElements: ['a', 'button'],
});

Options

OptionDefaultWhat it does
elementrequiredThe cursor wrapper element or a selector.
hideTrueCursorfalseHides the native cursor.
disableTouchtrueDoes not initialize on touch devices.
focusElements['a','button']Selectors or objects for hover states.
focusClassc--cursor-a--is-activeDefault class added on focus-element hover.
hiddenClassc--cursor-a--is-hiddenAdded when hidden, off-screen or before the first move.
clickingClassc--cursor-a--secondAdded during mousedown.
onInit / onDestroy / onMovenullCallbacks: (cursorEl), (cursorEl), (position, cursorEl).

focusElements

Strings are selectors. Objects add a class and callbacks.

focusElements: [
  'a',
  { elements: '.js--grow', focusClass: 'c--cursor-a--third' },
  {
    elements: '.js--text',
    focusClass: 'c--cursor-a--fourth',
    mouseenter(cursorEl, el) { /* ... */ },
    mouseleave(cursorEl, el) { /* ... */ },
  },
]

Methods

update(options)Merges options and re-binds focus elements. Call update({}) after injecting DOM.
disable() / enable()Hides / shows the cursor.
destroy()Removes listeners and cancels the animation frame.
